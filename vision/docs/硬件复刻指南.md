# EC 26 E 硬件复刻指南

本文根据当前代码、`.env.example` 和部署文件整理。它说明“软件已经明确依赖
什么”，不替代原机电气图纸。仓库没有记录的电机型号、电源电压/电流、驱动器
接线端子、机构尺寸和相机型号，均标为 **现场确认**；复刻前必须在原机拍照、
抄录铭牌并用万用表确认，不能由 GPIO 编号或默认值反推。

## 1. 系统总览

```text
USB 相机 ── USB/V4L2 ──┐
                       │
                 Radxa Cubie A7Z（Linux）
                       ├── UART3 /dev/ttyAS3 ── F32C 无刷旋转轴
                       ├── UART4 /dev/ttyAS4 ── Servo42C：X0、X1、Y、Z
                       ├── GPIO ─────────────── 电磁铁驱动、完成指示灯
                       ├── GPIO ─────────────── Task1/Task2 实体按键
                       └── A733 NPU ─────────── YOLO11 分割模型

相机画面 → A4 工作区定位 → 纸片检测与稳定性审查 → 拼图规划
→ 坐标/限位校验 → XY/Z/旋转轴/电磁铁动作
```

系统对象是蓝色横向 A4 工作区上的纸片。相机提供视觉坐标，机械机构执行取放。
软件保护只能降低失误风险，**必须另设可直接切断驱动使能或动力电源的硬件急停**。
实体按键不是急停。

## 2. 物料清单

| 子系统 | 已确认的软件/仓库依据 | 复刻时需要准备 | 需要现场确认 |
| --- | --- | --- | --- |
| 主控 | Radxa Cubie A7Z，Linux，带 A733 NPU | 同型号主板或能提供相同 GPIO/UART/NPU 的板端 | 系统镜像、内核、存储容量、散热与电源规格 |
| 相机 | USB UVC/V4L2，相机路径默认 `/dev/video0` | 支持 MJPEG 1280×720@30 fps 的 USB 相机、USB 线和固定支架 | 实际相机型号、焦距、安装高度、曝光/对焦方式 |
| 视觉模型 | `puzzle_seg_yolo11n_640_pcq_a733.nb`，A733 VIPLite | 随交接包的模型、匹配板端的 VIPLite 运行时 | 驱动版本与模型兼容性；当前评估使用运行时 2.0.3.2 |
| XY/Z | 同一 UART 上的 4 个 Servo42C 地址 | 4 个 Servo42C 驱动节点及相应 X 双电机、Y、Z 机构 | 电机/驱动具体型号、减速比、脉冲当量、供电、限位开关和机械传动 |
| 旋转轴 | WHEELTEC F32C，无刷云台电机控制器 | 1 套 F32C、旋转机械轴、独立 UART 线 | 电机型号、编码器/机械零位流程、电源和安装正方向 |
| 末端执行器 | 高电平使能的电磁铁输出 | 电磁铁、**独立驱动级**（MOSFET/继电器等）、续流保护、受控电源 | 电磁铁额定电压/电流、驱动板型号、低/高电平逻辑是否与原机一致 |
| 人机接口 | 两个低有效按键、一个高有效完成 LED | 两个常开按钮、LED、合适限流电阻/驱动 | 排针电平、电路是否已有上下拉、LED 极性与额定参数 |
| 工作台 | 蓝色横向 A4 作为视觉基准 | 尺寸准确、颜色稳定的 A4 蓝色底板与黑色/低反光背景 | 相机安装位置、照明、蓝纸材料和纸片规格 |

> 电磁铁不能直接由主板 GPIO 供电。GPIO 只应连接到已验证的逻辑输入；电磁铁
> 电流必须由外部驱动和电源承担，且与主板正确共地/隔离。具体电路由现场电气设计
> 决定。

## 3. 已确认的接口与映射

### 3.1 UART 与运动地址

| 功能 | Linux 设备 | 正式参数 | 备注 |
| --- | --- | ---: | --- |
| XY 与 Z 的 Servo42C 总线 | `/dev/ttyAS4` | 115200 baud、8N1、无流控 | 不得与 F32C 共用 |
| X 左/第 0 驱动 | `/dev/ttyAS4` | 地址 `0xE0` | 软件名 `X0` |
| X 右/第 1 驱动 | `/dev/ttyAS4` | 地址 `0xE1` | 软件名 `X1`；与 X0 共同构成 X 轴 |
| Y 驱动 | `/dev/ttyAS4` | 地址 `0xE2` | 软件名 `Y` |
| Z 驱动 | `/dev/ttyAS4` | 地址 `0xE3` | 软件名 `Z` |
| F32C 旋转轴 | `/dev/ttyAS3` | 地址 `2`，默认 15 RPM，最高 30 RPM | 独立 UART3 |

复刻时先断开机械负载或让机构悬空，逐个确认串口、地址和正方向。UART 的物理
TX/RX/GND 针脚编号、是否需要电平转换、终端电阻和电源线不在仓库中记录，必须
查主板与驱动器资料并以原机实物为准。

### 3.2 GPIO 排针映射（仅对当前 A7Z 内核映射有效）

| 功能 | A7Z 物理引脚 | GPIO 设备 / line | 电平语义 | 代码位置 |
| --- | ---: | --- | --- | --- |
| 电磁铁控制 | 3（PJ23） | `/dev/gpiochip0` / `311` | 高=上磁，低=消磁 | `.env.example` |
| 完成提示 LED | 33 | `/dev/gpiochip1` / `35` | 高=亮，低=灭 | `actuation/led.py` |
| Task1 按键 | 35 | `/dev/gpiochip0` / `38` | 按下接 GND，低有效 | `deploy/systemd/README.md` |
| Task2 按键 | 37 | `/dev/gpiochip1` / `36` | 按下接 GND，低有效 | `deploy/systemd/README.md` |

按键输入由程序申请内部上拉，因此每个常开按钮应连接“对应 GPIO 与 GND”；不要
外接到电源正端。按键服务启动后先等待两键稳定松开，消抖为 30 ms。物理 40 脚
不申请、不监听。

GPIO line 是操作系统中的逻辑编号，**不等于排针号**，并且可能随内核/设备树
改变。新板必须用 `gpioinfo` 等工具重新验证映射；验证前请勿接上电磁铁驱动。

## 4. 机械与坐标约定

软件的 XY 绝对工作范围为 X=`0..230 mm`、Y=`0..360 mm`。默认坐标中 X 增大
向左，Y 增大向上；Z 正角度向上。A4 视觉坐标转电机坐标的公式为：

```text
电机 X = A4 X + MOTION_A4_ORIGIN_X_MM
电机 Y = A4 Y + MOTION_A4_ORIGIN_Y_MM
```

当前模板值为 X 偏移 `14.5 mm`、Y 偏移 `3.5 mm`；这只是原机标定值，复制机构
后必须重新测量。所有取放点会在量化到 `0.01 mm` 前后检查软件限位，但仍要安装
物理限位、机械止挡或驱动器自身保护。

F32C 的业务旋转不是“最短路径”：从机械零位顺时针转到目标角度，再按相同角度
逆时针回零。若实际安装方向相反，将 `.env` 的
`MOTION_ROTATION_CLOCKWISE_SIGN` 改为 `-1`，并在低速空载下重新验收。

## 5. 供电、接地与安全要求

以下属于复刻必须满足的工程要求，但额定数值应由器件铭牌/原机确认：

1. 主板、相机、逻辑 GPIO、Servo42C、F32C 和电磁铁动力电源分区规划；不得让
   电机或电磁铁电流经过主板 GPIO 或 USB 地线。
2. 若 UART 和 GPIO 直接连接，先确认双方逻辑电平兼容；不兼容时使用合适的
   电平转换或隔离器。
3. 电磁铁线圈是感性负载，驱动级需具备合适的续流/浪涌抑制；不要把该保护寄望于
   软件在 0.3 秒内关断。
4. 在驱动器使能、动力电源和末端执行器之间设置实体急停；急停动作应独立于
   Linux、Python 和按键服务。
5. 首次上电前测量短路和输出电平；每次改线均断开动力电源。调试时让人员远离
   运动范围，先低速、空载、单轴执行。

## 6. 相机与工作台搭建

当前正式采集配置是 MJPEG、1280×720、30 fps；软件用 FFmpeg 从 V4L2 读取。
YUYV 1920×1080 在原机最高约 5 fps，不适合当前检测链路。建议用
`/dev/v4l/by-id/` 下的稳定设备链接替代易变的 `/dev/video0`。

相机需垂直/近垂直覆盖完整蓝色横向 A4，四条边都不能碰到画面边界。工作区定位
先按 `.env` 中的 `WORKSPACE_DETECT_WIDTH×HEIGHT` 粗搜，再在原分辨率精拟合；
校正输出为横向 A4，默认 `764×540`。复刻后应固定相机支架、照明和工作台，再
重新填写两份任务 JSON 里的 `reference_corners_relative`。

推荐验收命令（会访问真实相机并写录像）：

```bash
poetry run python tests/external/cam/record_camera.py --duration 10
poetry run python tests/external/cam/record_detected_video.py
```

先确认原始视频曝光稳定、蓝色 A4 全部入画，再看标注视频中的 A4 四角和纸片轮廓。
若 A4 任一边被遮挡或出界，程序应报告失败，不应通过放宽阈值强行运行。

## 7. 从零复刻的验收顺序

按下列顺序推进；任一步失败时先修复，不要跳到正式任务。

1. **软件环境：** 不连接运动硬件，安装依赖并运行 `ec-26-e --help`、unit 和
   integration 测试。
2. **板端识别：** 确认 `/dev/video*`、`/dev/ttyAS3`、`/dev/ttyAS4`、
   `/dev/gpiochip0`、`/dev/gpiochip1` 存在且当前用户有权限。
3. **按键与 LED：** 先只接低压逻辑，运行
   `tests/external/gpio/test_buttons.py`；确认物理 35/37 脚低有效。LED 在任务
   完成路径验证前不要假设其引脚映射可复用。
4. **相机和视觉：** 固定相机与灯光，录制并检查检测视频；在不接执行器时调好
   A4 参考角点与纸片模式。
5. **UART 通信：** 在驱动不带机械负载或急停可用时，以低速单独确认 F32C 和
   Servo42C 地址、方向、反馈与失能。
6. **单轴机械：** 使用 `tests/external/motion/` 的脚本，先 `--dry-run` 看命令，
   再用很小位移验证 X、Y、Z 和旋转轴。不得绕过 XY 状态机直接控制 X/Y。
7. **电磁铁：** 先断开线圈，示波/万用表确认 GPIO 驱动输入低=关、高=开；随后
   低风险接入线圈，确认释放与异常退出均会断磁。
8. **整机：** 开启 `EC_DRAW_ENABLED=true` 观察视觉结果；使用无价值纸片、低速和
   现场看守执行一次完整流程，最后才安装按键 systemd 服务。
