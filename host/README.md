# 拼图装置上位机

从仓库根目录启动：

```bash
host/start_host.sh
```

首次上电时，先将机构手动置于写字机机械限位角，再点击“建立原点并前往安全停靠点”。之后可用屏幕或实体按钮启动任务：

| 按键 | 任务 | 求解坐标 |
| --- | --- | --- |
| 1 | 第 1 问第 2 小问：固定四片 | 210×297 mm（历史已标定链路） |
| 2 | 第 2 问第 1 小问：白色随机碎片 | 207×292 mm（新版随机求解器，自动按 2/3/4 片选择拓扑） |
| 3 | 第 2 问第 2 小问：图案碎片外轮廓拼图 | 207×292 mm（忽略花纹） |

实体按键与屏幕按钮使用同一上位机任务入口：`gpiochip0` 的 line `36`、`40`、`39` 分别对应按钮 1、2、3。运行中新的按键请求会被忽略，暂停按钮可请求安全终止。

视觉只接收校正蓝纸左侧 `0%～52%` 内、且全部顶点均未越过边界的碎片；允许碎片跨过中线 `2%`，右侧执行器候选不会进入五帧稳定器或规划器。

完成灯平时为红色；最后一片确认释放并完成释放驻留后立即变为绿色，同时蜂鸣器（`gpiochip1` line `37`，低电平触发）短响两下，随后机构继续回安全停靠点。初始化和单独回停靠点不触发完成提示。

随机任务也可以先纯规划，不连接运动硬件：

```bash
cd ../handover-puzzle
../../.venv/bin/python run_task1_tangram.py --task-profile random-white
```

只有额外传入 `--execute` 并经上位机确认后，才会连接实际执行硬件。

## 仅检测与解算联调

上位机的“仅检测与解算（硬件隔离）”默认开启。此模式完整执行相机采集、
五帧稳定识别、拼图解算、坐标适配和计划预检，并在结果区显示拼合图；不会
连接写字机、F32C 或电磁铁，也不需要建立机械原点。模式同时禁用了“安全
停靠”按钮，避免调试时误开串口。

命令行可使用同等的硬件隔离参数：

```bash
../../.venv/bin/python run_task1_tangram.py --task-profile random-white --plan-only
```

`--plan-only` 与 `--execute` 互斥。需要实机比赛时，先关闭该开关，再按原有
流程建立原点、前往安全停靠点并执行。

## 可更换 USB 设备

`task1.tangram.env` 中的 `CAMERA_DEVICE_PATH` 与正式执行参数中的写字机
串口都采用“配置优先、失效后自动发现”。配置路径仍可固定为稳定的
`/dev/v4l/by-id/...`、`/dev/serial/by-id/...`；若该路径不存在（摄像头也包括
路径存在但无法打开），程序只会在现场恰有一个 V4L2 摄像头或一个 USB 串口
候选时自动选中它，并将实际选择打印到上位机日志和命令行。候选不止一个时会
明确报错并列出候选，绝不会猜测设备。

纯检测/解算模式只解析摄像头，绝不扫描或连接写字机串口；相机未接入时会
每 2 秒自动重试发现，接入后自动恢复预览。写字机仅在正式任务确认 `RUN`
后才进行一次解析和连接：因此可以在上位机启动后再接好设备、再启动正式
任务，但不会在空闲预览时触碰串口。F32C 的 `/dev/ttyAS3` 和 GPIO 编号仍是
板载硬件固定配置，未作自动发现。

空闲预览的“预览蓝纸参数”独立于“正式视觉预设”。默认的“宽松自适应”会
分别尝试多组蓝纸 HSV 候选，并只在候选通过矩形结构检查后选取最佳结果；若
全部严格候选失败，界面会显示橙色“最佳努力 A4 候选”，但不会把它用于执行。
启动任务时仍只传递正式 `current/new` 预设给运行器，不会把调试卡纸的 HSV
参数带入正式任务。
