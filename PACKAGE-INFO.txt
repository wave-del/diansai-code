快速开始
--------
python3 -m venv .venv
.venv/bin/pip install -r handover-puzzle/requirements.txt
host/start_host.sh

说明
----
- 模型和原生库仅适用于 ARM aarch64 / A733 VIPLite 平台。
- host/start_host.sh 会把 model-lib/ 加入 LD_LIBRARY_PATH。单独运行 vision/ 工程时，
  如系统未预装 libNBGlinker.so / libVIPhal.so，请把本包的 model-lib/ 加入 LD_LIBRARY_PATH。
- 首次上电需先人工把机构放到机械限位角，再建立原点。
- 视觉模型与厂商运行库不随上游 Git 仓库分发，本包为内部交接用途。
